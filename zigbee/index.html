Zigbee & How Does It Work?

Why Zigbee?

When you think about buying a smart light switch or any similar device, you’d think about connectivity: how does the device send and receive data?

  • Wired (like KNX): most reliable but the issue is cost, and it needs special cables in the building.
  • Wi-Fi: good for a small number of devices, the more you add, the more lag and limited bandwidth you get.
  • Bluetooth: occasional disconnects and mostly no remote control (only when you’re nearby)
  • Zigbee and Thread: protocols made specifically for IoT

Zigbee wins because it’s a mesh (every non-battery powered device extends the network), it handles many devices without slowing down (it gets stronger and more reliable), and it works without the internet.

How Zigbee Works

All [Zigbee](a site) devices communicate with the Coordinator which is my SLZB-06M, which connects to my home network via ethernet, and Zigbee2MQTT connects via TCP , there’s no technical reason to use ethernet and I could’ve easily used USB but my NAS/Server is far from all devices in the basement and connected to the same network switch. From there, Zigbee2MQTT passes it through Mosquitto (MQTT) to which my Home Assistant is subscribed. Home Assistant has a good integration called HomeKit Bridge which adds select devices to Apple Home for integration with the Apple ecosystem.
